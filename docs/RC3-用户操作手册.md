# 工业销售管理系统 用户操作手册（2.1.0-rc3 · 两板块）

> 适用于局域网安装版。安装、备份、升级见《LAN安装使用手册》《备份恢复与升级手册》；本手册只讲**日常业务操作**。
> 本版为验收候选（非正式版）：模板签收、财务黄金用例、Windows 实机与现场 UAT 完成前，正式报价以负责人签收为准。

## 1. 谁用哪个板块

登录后左侧菜单顶部显示所在板块：

| 板块 | 使用者 | 主要菜单 |
|---|---|---|
| **商务工作区** | 部门负责人、商务助理、财务 | 工作台、询价登记、项目台账、报价中心（负责人/商务/财务）、合同与执行、业绩台账、对外案例、客户资料库、产品型号库 |
| **销售工作区** | 销售 | 工作台、售前项目、项目进度查询、客户资料库、我的业绩、对外案例 |
| 技术设置 | 管理员（以及需要的人） | 系统设置：账号、出具主体、阶段配置、运行状态 |

菜单只是方便；真正的权限由服务器判断。没有权限的按钮不显示，即使绕过页面直接调用接口，也会被拒绝（403）。

## 2. 销售：售前跟进 → 中标后只读

1. **登记项目**：售前项目 → “+ 新建项目”。可以先不关联客户，之后在“参与方”中关联主机厂/业主/投资方。
2. **售前跟进**：项目页 → “+ 售前跟进”。“发生时间”可以回填（例如补录上周的拜访），**不能填未来时间**；系统另外记录“录入于”（服务器时间，不能修改）。
3. **中标后**：商务或负责人点击“中标确认 · 转交商务”后，项目顶部显示“已中标 · 已转交商务”和“销售只读：只能查看进度”。
   此后销售不能再修改项目资料、参与方、售前跟进、项目附件（页面按钮隐藏，接口返回 403）；仍然可以查看：
   - **交付与资金状态**：生产中/已发货/已到货……；预付款已到账/尾款待收……（**只有状态，没有任何金额**）；
   - 商务填写的“销售可见说明”；
   - **操作记录**页签：谁在什么时间做了什么动作（不含内部说明与价格）。
4. **我的业绩**：可按年份、行业、主机类型、地区等筛选，点击“导出内部 PDF”得到当前筛选结果的**内部安全版**。PDF **默认只包含“已确认”业绩**；如需待核实或已撤销的记录，在按钮旁的下拉框中明确选择“仅待核实 / 仅已撤销 / 全部状态”，PDF 标题会写明所选范围
   （页眉显示筛选条件、生成人、时间、页码；无金额、合同号、单价、内部备注；带“公司内部资料 · 禁止外发”水印）。
   **这份 PDF 不是对外案例**，不得发给客户；对外请使用“对外案例”生成案例册（只包含负责人批准公开的业绩）。

## 3. 商务助理

1. **询价登记**（商务工作区 → 询价登记）：记录客户/主机厂发来的询价——项目、询价方、收到日期、要求回复日期、需求说明、产品明细（型号/名称/数量/单位）。
   **询价不记价格**：明细里出现价格/金额字段会被拒绝。询价编号为 `XJ-`。
   每条询价可点“登记单 PDF”打印/下载内部《项目询价登记单》（标注“非对外正式报价 · 不含价格字段”，已关闭的询价也可下载；每次生成留痕）。对客户报价请使用报价中心的正式报价单。
   注意：登记单不含结构化价格字段，但“需求说明”“备注”是人工填写的文字，系统不会自动识别其中的金额——**请勿在这两处填写价格**，外发前人工核对。
2. **报价**：报价中心 → 新建报价，可选择“关联询价”（必须是同一项目的询价）。询价状态自动计算：有关联报价（草稿、已生成）为“**报价中**”；报价标记“已发送”后为“**已报价**”（之后失标仍算已报价）；关联报价全部作废则回到“待报价”。人工只能“关闭/重新打开”询价，已关闭的询价不会被自动改回。
   报价的模板、冻结、试用水印、签收规则与 RC2 相同。
3. **中标确认 · 转交商务**：项目页按钮；可填写中标说明。中标可以早于合同/订单。之后销售只读。
   误操作或最终失标由**负责人**“撤销中标”（必须写原因；已有有效合同/订单时需先撤销订单）。
4. **生产/交付状态**：项目全景 → 交付与资金状态 → “+ 记录交付状态”。选择阶段、发生日期，分别填写：
   - **销售可见说明**（不要写金额）；
   - **内部说明**（销售看不到）。
   录错的记录在“状态历史”中“撤销”（必须写原因；只做标记，不删除）。撤销原因只在“状态历史”中对该状态线的维护人可见，项目动态里只显示“录错已撤销”。
5. **阶段配置**（系统设置 → 阶段配置）：可以改阶段的中文名称、顺序、停用；不能删除，阶段代码和“完结”属性不能改（“已交付/完结”“已结清”是固定的完结阶段）。已记录的历史仍显示当时名称（改名后状态历史另标“现名”）；停用的阶段不能再被新记录选择。
6. **多张合同/订单的项目**：交付线和资金线记录的是**项目总体状态**，不是每张合同各自的状态（首期不做分批履约）。项目有 2 张及以上有效合同/订单时，页面会提示；记录“已交付/完结”或“已结清”前必须勾选“已覆盖全部合同/批次”，系统记录操作人与时间。之后如果又新增、撤销或替换了合同/订单，页面会显示“**完结确认已失效，需重新确认**”，请核实后重新记录并勾选。各合同/批次的差异写在说明里。
7. **交付期限**：项目资料中填写“约定交付日期”，超过该日期且交付线未到“已交付/完结”时，项目显示“交付已逾期”。

## 4. 财务（默认“商务口径”）

财务默认可以：新建/修改项目资料与参与方；登记询价；**制作三公司报价**（新建、编辑、生成正式 PDF、标记发送、查询历史价格，与商务相同）；登记合同/订单（不录合同金额）；补录/修改业绩的**非金额字段**；记录生产/交付状态和**资金状态**。

- **资金状态只记状态，不记金额**：未确认 / 预付款已到账 / 尾款待收（存在欠款）/ 已结清 / 有争议。金额请写在“内部说明”或公司财务系统中——销售看不到内部说明。
- 财务能看到报价单价和报价总额，但**看不到合同金额和业绩内部金额**，也不能签收模板、审批业绩、修改公开授权（2026-11-22 负责人决策 D-2）。如需临时关闭财务报价，管理员在 `config\app.env` 设置 `ISH_FINANCE_QUOTE=0` 并重启。
- 如甲方要求恢复 RC2 的旧口径（财务只确认合同、维护执行节点），设置 `ISH_FINANCE_SCOPE=RC2` 并重启。

## 5. 部门负责人

除商务的全部操作外：模板签收、撤销中标、业绩审批/公开授权、合同金额、案例册撤回、审计日志查看。

## 6. 创建人、修改人与时间

- 项目页顶部：“创建：某某 时间 ｜ 最后修改：某某 时间”。
- 跟进/进展：“发生 …（业务发生时间，可回填）· 某某 录入于 …（服务器时间）”。
- 交付/资金状态：“发生：日期 ｜ 记录：某某 时间”。
- 业绩、询价列表显示登记人/最后修改人与时间。
- 报价条款、报价行新增/改价/删行、联系人修改、项目资料修改都会写入审计（记录被修改的**字段名**，不记录价格值）；审计与业务保存在同一事务，保存失败不会留下审计。

## 7. 常见问题

| 现象 | 原因 / 处理 |
|---|---|
| 销售看不到“编辑项目” | 项目已中标转交商务，或不是本人负责/参与的项目 |
| 记录状态提示“请先中标确认” | 两条状态线从中标确认后开始记录 |
| 资金状态里找不到金额 | 设计如此：金额不进入状态线，写在内部说明或财务系统 |
| 内部 PDF 里没有金额 | 设计如此：内部 PDF 是安全版；含金额的内部台账请负责人/商务用“导出 Excel” |
| 询价保存失败“不记录价格” | 明细中含价格字段，删除后再保存 |
| 同一项目有多张合同/分批交付 | 本期一个项目只有一条主交付状态线；分批情况写在说明中（见剩余问题 F13） |

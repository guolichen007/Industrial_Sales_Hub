## B. 已知限制（本期接受，已在文档中说明）

1. **安装路径必须是 ASCII**（可含空格）：PostgreSQL Windows 版按系统代码页处理路径，中文路径会导致数据库无法启动。安装脚本会拒绝并提示。
2. **HTTP 试用模式下会话 Cookie 不是 Secure**：这是 HTTP 能登录的前提；只适用于隔离内网。
3. **登录限速**按“来源 IP + 用户名”与“用户名全局”计数：若将来放在反向代理之后且未配置 `ISH_TRUSTED_PROXY`，所有客户端来源 IP 相同，恶意用户可能让某个用户名暂时无法登录 15 分钟（管理员可在系统设置中重置密码作为应急）。
4. **执行节点备注、公开简介等自由文本**：系统只做字段级隔离与生成前人工确认，不承诺自动识别文本中的金额。
5. **项目附件对可编辑该项目的销售可见**：若附件中放了报价单，负责销售能看到。规范要求报价 PDF 只在报价中心管理，不作为项目附件上传（已写入手册）。
6. **PDF 字体**：内置 DroidSansFallback + DejaVu Sans（可分发许可），字形风格与微软雅黑不同；如甲方要求使用已授权的商业字体，可通过 `PDF_FONT_PATH` 指定本机已安装字体（不随包分发）。
7. **WinSW 2.12.0 未带 Authenticode 签名**（上游未签名），已记录 SHA256；PostgreSQL（EnterpriseDB）与 VC++（Microsoft）签名已核验，Python 包 sigstore 已核验。
8. **性能数据来自 2 核 3 GB 沙箱**，不是目标主机；现场需复测。

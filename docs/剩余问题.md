## B. 已知限制（本期接受）

1. 安装路径必须 ASCII（可含空格），不得含 `& < > " ' % ! ^ ; ` $`；同一主机仅一套安装。
2. HTTP 试用模式 Cookie 非 Secure，只适用于隔离内网。
3. 登录限速按“来源 IP + 用户名”；反向代理后必须配置 `ISH_TRUSTED_PROXY`，否则所有来源 IP 相同。
4. 自由文本（跟进、公开简介等）不承诺自动识别金额；对外内容使用独立字段 + 预览 + 人工确认 + 撤回。
5. 附件：默认内部；只有“交付/进度”类附件经商务/负责人授权才对销售可见。删除附件只解除系统访问，文件本体留在私有目录（备份/审计追溯）。
6. 维护窗口内登录/登出仍可执行，`last_login` 与登录审计可能晚于备份快照（非业务数据，已说明）。
7. PDF 字体为内置 DroidSansFallback + DejaVu Sans（可分发）；如需微软雅黑等商业字体，用 `PDF_FONT_PATH` 指定本机已授权字体。
8. WinSW 2.12.0 上游未签名（已记录 SHA256）；PostgreSQL、VC++ 签名与 Python sigstore 在构建时核验。
9. 性能数据来自 2 核沙箱，非目标主机。
10. 产品图片（R-031）、跟进单条附件（R-061）、参数字典维护界面（R-032）、客户/项目/报价列表导出（R-140）为首期后续小步。
11. 计划任务以 SYSTEM 运行，异盘副本指向网络共享时需为主机计算机账户授权，现场单独验证。
12. **历史提交中出现过真实样张文件名**（RC1 提交 4025692 的模板说明文档，已在 RC2 中改为私有编号）。按任务书不强推、不改写历史；
    如负责人认为文件名中的客户名称属于敏感信息，需由负责人决定是否对远端历史做专门处理。

| 项 | 处理 | 原因 |

| 可见不可编辑项目的附件列表 | 由 403 改为 200 + 仅授权交付附件 | 否则无法向销售提供授权的交付文件；内容与直链仍 403 |

## E. RC3 已知限制

1. 资金状态线**只记状态不记金额**，不是财务总账；回款金额、发票不在本系统（按任务书不做 ERP/总账）。
2. 内部业绩 PDF 单次最多 1000 条；含金额的内部台账请使用负责人/商务的 Excel 导出。
3. 项目“操作记录”只列项目相关的安全动作；完整审计仍在“审计日志”（管理员/负责人）。
4. 原“执行节点”保留并可继续使用（兼容 RC2），新进度以两条状态线为准；迁移只把已完成/进行中的最远节点转为交付线初始事件，资金线不推测历史。
5. 自由文本仍可能被人工写入金额：销售只读取 `public_*` 字段，内部文本不返回给销售；但“销售可见说明”本身由录入人负责不写金额（页面有提示）。

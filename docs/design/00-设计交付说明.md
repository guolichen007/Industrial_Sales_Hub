# 工业销售管理系统 V2.0｜设计交付说明

> 交付时间：2026-11-12。状态：项目设计和前端交互演示，**尚未正式编码后端、部署云服务器或获得甲方最终范围签字**。

## 使用顺序

1. **04_项目设计评审稿.docx**：9 页 Word，适合内部审查与向甲方解释项目整体架构。
2. **02_交互式前端原型.html**：用 Chrome/Edge 双击打开，体验前端信息架构、角色、客户、项目、报价和业绩/案例。所有数据为虚构演示，保存于浏览器本地（存储可用时）；浏览器打印可选“另存为 PDF”，不等于正式服务端 PDF。
3. **05_二轮关键决策确认表_6题.docx**：向甲方再核对 6 个会改变开发范围的问题，每项只需填 1/2/3。
4. **01_项目总体方案与PRD.md**：项目负责人详细审查和完整设计逻辑，可在 VS Code/Typora 阅读。
5. **03_Codex开发执行任务书.md**：给工程师/Codex 的 G0～G4 任务、API 设计和测试门禁，务必先走 G0。

## 前端原型如何操作

- 右上角切换角色：部门负责人、商务助理、销售、财务、管理员。
- **项目中心**：查看多参与客户关系和完整进度；打开项目详情记录售前/执行日志。
- **报价中心**（商务、负责人、管理员）：新建报价 → 选择公司/项目/接收客户 → 选参数 → 改价 → 加行 → 生成预览 → 浏览器打印。
- **业绩台账**：补录“待核实”记录 → 负责人确认 → 对外案例页面勾选已确认条目；公开版预览刻意不携带内部金额字段。
- **项目执行**：商务与财务添加执行阶段节点；销售界面只展示共享进度摘要。
- **方案与架构**：已确认项、待确认项、G0～G4 门禁。

## 当前设计与真实系统的边界

- 演示版没有服务器、数据库、真实权限、附件存储、备份和正式 PDF 生成。
- 原型角色切换/菜单隐藏仅是交互演示，**不是生产安全机制**。必须由后端 API、数据库查询和文件下载同时实施授权。
- 当前报价使用虚构公司/金额/项目；三份用户报价样本用作功能/模板需求参考，没有当作正式商业文件输出。
- 甲方本地软件与实时同步的概念存在歧义，本方案建议云端网页+桌面快捷方式；真正离线双向同步不属于首期。
- 公开案例首次对外发布还应核实业主名称、项目照片和证明材料的授权；首期不自动发布未经确认的内容。

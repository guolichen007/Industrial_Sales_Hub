# ADR-003 权限、脱敏与部署安全基线

- 日期：2026-11-19

## 权限模型

- 五个角色：ADMIN / LEADER / ASSISTANT / SALES / FINANCE；能力表集中在 `apps/common/roles.py` 的 `CAP`，是唯一授权来源。
- **前端菜单隐藏只是体验**。每个 API 都在服务端检查能力；销售直接调用报价接口返回 403（自动化测试 + 浏览器测试均验证）。
- **行级范围**：销售只能看到自己负责/创建/参与的项目（`apps/projects/scope.py`），附件、订单、业绩查询均复用此范围。
- **字段级**：同一资源按角色使用不同序列化器。销售的项目、业绩、产品接口在 JSON 中**根本不包含**金额字段（不是靠前端隐藏）。
- **两条进度线分别授权**：售前跟进（销售+商务可写）；合同执行与执行节点（商务+财务可写，销售只读）；财务信息（仅负责人+财务）。

## 对外案例脱敏

- 案例只能从“已确认 + 允许对外展示”的业绩中选取。
- 唯一取数入口 `apps/performances/public.py` 使用字段白名单；PDF 渲染前再次断言不含白名单外字段。
- 业主名称只有勾选“已获授权公开”时才出现；主机厂、投资方、金额、内部备注、订单号永不进入对外材料。
- 测试对预览 API、生成记录、PDF 字节、PDF 元数据、PDF 文本层逐一扫描敏感值。

## 部署安全

- 仅 Nginx 暴露 80/443；PostgreSQL 与应用容器只在内部网络。
- HTTPS 强制、HSTS、Session/CSRF Cookie 仅 HTTPS、CSP、`nosniff`、API 响应 `no-store`。
- 登录失败限速（同 IP+用户名 15 分钟内 8 次）。停用账号立即清除其全部会话。
- 附件：扩展名白名单 + 文件头签名校验 + 20MB 上限；Excel 导入只接受 .xlsx 且以只读/仅值模式读取，不执行宏和公式。
- 审计：登录、创建/修改、生成 PDF、下载、确认/撤销、导入均写审计，审计详情中自动遮蔽金额与密码字段。
- `manage.py check --deploy` 中保留的 4 项警告及原因写在 `config/settings.py` 的 `SILENCED_SYSTEM_CHECKS` 注释中。
